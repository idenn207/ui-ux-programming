## 전체 흐름 확인

### 데스크톱에서

- [ ] 메뉴 세 개가 각각 맞는 영역으로 이동하고 주소의 `#` 값도 맞습니다.
- [ ] 현재 메뉴 하나만 강조되고 브라우저 뒤로 가기·앞으로 가기를 해도 강조가 따라갑니다.
- [ ] 계획 두 건 중 한 건을 취소한 뒤 전체·저장됨·취소됨의 카드 수와 제목이 맞습니다.
- [ ] 결과가 없는 필터에서 안내가 보이며 다른 필터를 선택해 계속 탐색할 수 있습니다.
- [ ] 9주차의 입력 검증, 저장, 카드 **내용 보기**, 취소 기능이 그대로 작동합니다.

### 모바일에서

- [ ] 600px 이하에서 메뉴 버튼과 접힌 메뉴가 나타나며 가로로 넘치는 요소가 없습니다.
- [ ] 버튼을 반복해서 누를 때 메뉴, 버튼 문구, `aria-expanded`가 함께 바뀝니다.
- [ ] 링크를 선택하면 해당 영역으로 이동하고 메뉴가 닫힙니다.
- [ ] 카드와 입력창이 잘리지 않고 버튼을 누를 수 있습니다.
- [ ] Tab 키로 보이는 링크와 버튼을 순서대로 이동할 수 있습니다.
