## 폼 UI 구조 체크리스트

- [ ] 레이블을 눌렀을 때 연결된 입력칸으로 초점이 이동합니다.
- [ ] 안내·글자 수·오류 문장이 입력 필드 가까이에 표시됩니다.
- [ ] 조건부 영역을 닫으면 화면과 제출 데이터에서 함께 제외됩니다.
- [ ] 기본·초점·조건 충족·오류 상태를 색과 문장으로 구분합니다.
- [ ] 오류를 수정하면 현재 값으로 다시 검사해 상태가 갱신됩니다.
- [ ] 단계가 바뀌면 제목으로, 오류가 생기면 첫 오류 입력으로 초점이 이동합니다.
- [ ] 버튼을 누르거나 Enter를 눌러도 같은 submit 검증이 실행됩니다.
- [ ] 저장 중에는 중복 제출을 막고 처리 상태를 표시합니다.
- [ ] 저장 완료와 실패가 다른 문장으로 표시되고, 실패해도 입력값이 남습니다.
- [ ] 새 계획을 시작하면 입력값과 화면 상태가 모두 초기화됩니다.
