# TeraB 서비스 소개 페이지

개인 NAS 사용자를 위한 파일 관리 서비스 TeraB의 소개 페이지입니다.

- **GitHub Repository URL**: <https://github.com/idenn207/ui-ux-programming/>
- **Published Website URL**: <https://idenn207.github.io/ui-ux-programming/step8/>

## 새로 추가한 것

선택한 이용 옵션으로 월 이용료를 계산하고 청구서를 발송하는 기능을 추가했습니다.
신청 설정은 4단계로 진행되며, 발송한 청구서는 다시 조회하거나 취소할 수 있습니다.

## 기능 변경사항

- 신청 설정을 모달로 변경, 단계 표시(O - O - O - O) 추가
- 저장 용량 1~10TB 선택, 용량별 금액 표시
- 추가 서비스 단계 추가 (링크 공유, 자동 백업, 전담 기술 지원, SSO 계정 연동)
- 요금 계산과 청구서 내역 모달 추가
- 청구서 발송, 조회, 발송 취소 기능 추가
- 다크 모드 버튼을 화면 상단으로 이동
- 이름 입력을 도입 문의 폼으로 통합, 전화번호와 회사명 추가
- 개인정보 수집 동의와 이용 약관 동의를 도입 문의 폼으로 이동
- 이용 옵션 선택과 도입 문의를 좌우 2단 배치로 변경
- 입력 오류 안내를 각 입력창 아래로 이동
- 이용 방법 문구 수정

## 새 기능의 사용자 흐름

1. 이용 옵션 선택 (4단계)
   - 행동: 'TeraB 옵션 선택' 클릭 후 이름, 용량, 추가 서비스를 선택한다.
   - 조건: 저장 공간 이름이 비어 있지 않은가?
   - 성공: 선택한 내용과 월 합계를 확인 단계에 표시한다.
   - 오류: 이름이 비면 안내를 표시하고 다음 단계로 넘어가지 않는다.
   - 결과 없음: 추가 서비스를 고르지 않으면 '선택한 추가 서비스가 없습니다'를 표시한다.
   - 다음 행동: '다음'으로 설정을 완료한다.

2. 설정 완료
   - 행동: 확인 단계에서 '다음'을 클릭한다.
   - 성공: 이용 옵션 선택 카드와 도입 문의 카드에 선택 내용과 청구 금액을 표시한다.
   - 다음 행동: '청구서 받기'로 도입 문의로 이동한다.

3. 청구서 확인과 발송
   - 행동: 담당자 정보를 입력하고 '청구서 확인하기'를 클릭한 뒤, 모달에서 '청구서 발송하기'를 클릭한다.
   - 조건: 설정을 완료했는가? 이름, 이메일, 전화번호 형식이 맞는가? 두 동의에 체크했는가?
   - 성공: 청구서 모달을 열고, 발송하면 버튼이 '발송 완료'로 바뀐다.
   - 오류: 조건을 못 채우면 해당 입력창 아래에 안내를 표시한다.
   - 다음 행동: 청구서를 조회하거나 발송을 취소한다.

4. 조회와 취소
   - 행동: '청구서 조회하기' 또는 '발송 취소하기'를 클릭한다.
   - 성공: 조회는 발송한 내역을 다시 보여 주고, 취소는 발송 상태를 되돌린다.
   - 다음 행동: 다시 발송하거나 '다시 설정하기'로 초기화한다.

## 테스트 기록

### 신청 설정

| 경로 | 조작                                    | 결과                                             |
| ---- | --------------------------------------- | ------------------------------------------------ |
| 정상 | 7TB, 링크 공유 3개, 자동 백업, SSO 선택 | 월 합계 298,000원이 확인 단계와 두 카드에 표시됨 |
| 오류 | 저장 공간 이름을 비우고 '다음'          | 안내 표시, 단계 유지                             |

### 청구서 발송

| 경로 | 조작                                | 결과                                        |
| ---- | ----------------------------------- | ------------------------------------------- |
| 정상 | 담당자 정보 입력 후 발송            | 청구서 내역 표시, 버튼이 '발송 완료'로 바뀜 |
| 오류 | 이름, 이메일, 전화번호, 동의 미입력 | 해당 입력창 아래 안내 표시                  |
| 오류 | 설정 완료 전 '청구서 확인하기'      | 안내 표시 후 이용 옵션 선택으로 이동        |

### 발송 이후

| 경로 | 조작              | 결과                                            |
| ---- | ----------------- | ----------------------------------------------- |
| 조회 | '청구서 조회하기' | 발송한 내역이 그대로 표시됨                     |
| 취소 | '발송 취소하기'   | 버튼이 '청구서 확인하기'로 돌아가고 입력값 유지 |
| 수정 | '다시 설정하기'   | 선택과 발송 상태가 모두 초기화됨                |
