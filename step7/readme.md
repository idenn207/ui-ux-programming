# TeraB 서비스 소개 페이지

개인 NAS 사용자를 위한 파일 관리 서비스 TeraB의 소개 페이지입니다.

- **GitHub Repository URL**: <https://github.com/idenn207/ui-ux-programming/>
- **Published Website URL**: <https://idenn207.github.io/ui-ux-programming/>

## 사용자와 목표

- 사용자: 개인 NAS로 스토리지를 구축해서 쓰는 사람
- 목표: TeraB를 신청할 때 적용할 이용 옵션을 선택하고, 선택한 내용을 확인한 뒤 신청 설정을 마친다.

## 사용자의 흐름

1. 개인정보 수집에 동의하고 'TeraB 신청 시작하기'를 누른다.
2. 저장 공간 이름을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 저장 용량을 선택하고 필요하면 링크 공유를 포함한다.
4. 이름, 용량, 링크 공유 설정을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터렉션 시나리오

1. 시작과 개인정보 수집 안내
   - 행동, 이벤트: 기존 동의 체크박스를 선택하고 'TeraB 신청 시작하기'를 클릭한다.
   - 조건: 개인정보 수집 동의가 선택되었는가?
   - 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
     팝업에서 '돌아가기'를 누르거나 ESC를 누르면 동의를 해제하고 시작 화면에 남는다.
     '동의하고 신청 시작하기'를 누르면 이름 입력 화면을 연다.

2. 이름 입력
   - 행동, 이벤트: 저장 공간 이름을 적고 '이용 옵션 선택하기'를 클릭한다.
   - 조건: 앞뒤 공백을 지운 이름이 비어 있는가?
   - 반응, 다음 상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
     값이 있으면 저장하고 옵션 선택으로 이동한다.

3. 옵션 선택
   - 행동, 이벤트: 저장 용량을 바꾸나 링크 공유를 선택하고 '내용 확인하기'를 클릭한다.
   - 조건: 링크 공유를 선택했는가?
   - 반응, 다음 상태: 선택했을 때만 동시 공유 링크 수를 보여준다.

4. 내용 확인
   - 행동, 이벤트: 이름, 용량, 링크 공유 내용을 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
   - 조건: 수정인가, 완료인가?
   - 반응, 다음 상태: 수정하면 기본 값을 유지하고 옵션 선택으로 돌아간다.
     완료하면 완료 안내로 이동한다.

5. 완료와 다시 설정
   - 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
   - 반응, 다음 상태: 새 설정의 이름, 용량, 링크 공유, 진행 상태를 초기화하고 이름 입력부터 다시 시작한다.
     이미 확인된 개인정보 수집 동의와 다른 기능을 유지한다.
