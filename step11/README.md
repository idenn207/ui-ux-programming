## 11주차 웹 접근성 개선

- 개선한 요소: (예: 현재 메뉴 표시, 이미지 설명, 본문 바로가기, Esc 닫기)
- 정상 경로: (행동 → 화면·상태 반응 → 다음 행동)
- 다른 경로: (빈 입력/결과 없음/취소/모바일 메뉴 중 실제로 시험한 경우)
- 키보드 확인: 첫 Tab, Enter·Space, Esc, 초점 위치
- 모바일 확인: 600px 이하와 375px에서 메뉴·입력·버튼 조작
